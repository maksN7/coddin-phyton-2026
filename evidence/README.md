# Dev Evidence

Ця папка навмисно є тільки в гілці `dev`.

Файли містять:

- `git_log.txt` і `screenshot_git_log.png` — історія Git-комітів по лабораторних.
- `docker_containers.txt` і `screenshot_docker_containers.png` — два запущені контейнери API/PostgreSQL.
- `container_libraries.txt` і `screenshot_container_libraries.png` — список бібліотек усередині API-контейнера через Poetry.
- `postgres_tables.txt`, `postgres_seed_data.txt` і відповідні PNG — таблиці, поля та seed-дані PostgreSQL.
- `api_postman_style_verification.json` і `screenshot_api_postman_style.png` — перевірка GET/POST/PUT/DELETE та JWT-auth запитів.
- `lab_command_sequence.txt` — послідовність команд, використаних для виконання лабораторних.

Swagger UI доступний після запуску: `http://localhost:8000/docs`.
